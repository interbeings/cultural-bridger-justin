# Cultural Bridger - Justin

고1(2022 개정 교육과정) 고난도 문제은행 학습 앱입니다. 수학·영어·과학·사회는 고1 3·6·9월 전국연합학력평가(학평) 형식으로 구성했습니다. 수학·영어·중국어·과학·사회·사고력 6과목, 6,961문항(전 단원 50문항 이상, 수학 그래프·도형형·사례형·융합 심화 포함).

## 기능
- 계속 풀기(무제한) / 10·20·50문제 모드, 난이도(중상·상·최상)·단원·출제 범위 선택
- 과목별 오답노트(내 답·정답·해설, 다시 풀어 맞히면 자동 삭제)
- 단원별 정답률, 오늘·최근 7일 과목별 학습 문항 수와 시간
- 수학 단원 대분류: 공통수학1 · 1학기 / 공통수학2 · 2학기
- 영어 수능형 장문 세트(지문 1개 + 5문항)

## 학평 스타일 구성
- 수학: 5지선다 70% + 단답형 30%(자연수 직접 입력), 문항마다 [2점]/[3점]/[4점] 배점 표시
- 영어: 학평 독해 18~45번 유형(목적·심경·주장·함축·요지·주제·제목·도표·내용 일치·안내문·어법·어휘·빈칸·무관·순서·삽입·요약·장문)으로 단원 재편, [3점] 표시
- 과학(통합과학): 표 자료 해석형(정답 코드 계산)·학생 대화형·정리 노트형, 배점 [1.5점]/[2점]/[2.5점]
- 사회(통합사회·한국사): 사료 제시형·표 제시형(비교 우위)·학생 대화형·정리 노트형, 배점 [1.5점]/[2점]/[2.5점]
- 과목별 문항 수는 이전과 같습니다. 교체된 문항은 새 id를 받아 예전 학습 기록과 섞이지 않습니다.

## 파일
- `index.html` — 앱 (`bank.json`을 불러와 브라우저에서 실행)
- `bank.json` — 전체 문제 데이터
- `tools/` — 문제 생성·검산 스크립트 (`cd tools && python3 build.py && python3 mockstyle.py`로 bank.json 재생성)

## 문항 출처
수능·모의고사·EBS·HSK·SAT 유형과 난이도를 본뜬 자체 제작 변형 문항입니다. 수학·사고력·과학 계산형에는 같은 유형에 숫자를 바꾼 유사문항이 포함되며, 정답은 코드로 검산했습니다.

학습 기록은 사용하는 기기의 브라우저(localStorage)에만 저장됩니다.
